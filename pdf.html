Document utilities

PDF tools

Merge PDF files, extract selected pages, rotate pages and reduce PDF file size. Processing happens locally in your browser.

Merge PDF files

Combine multiple PDF files into one document. Reorder the list with the arrows.

    Extract / split PDF

    Save selected pages as a new PDF. Use page numbers and ranges, for example 1-3, 5, 8-10.

    Rotate PDF pages

    Rotate every page in the selected PDF by 90, 180 or 270 degrees.

    Compress PDF

    Reduce file size by converting pages to optimized images. This can remove selectable text, links, forms and accessibility data.

    Privacy: files are processed in your browser and are not uploaded by these tools. Very large or password-protected PDFs may fail depending on your device memory and browser. Compression to a specific size is best-effort; the final size depends on the PDF contents.
