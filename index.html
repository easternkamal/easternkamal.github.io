Nepali language utilities

Nepali Unicode converter

Type Nepali using English letters and convert it to Devanagari Unicode, or convert Unicode text back to a basic Roman transliteration.

Example: namaste → नमस्ते

This is a built-in, offline phonetic converter and does not send your text to a server. Romanized spelling can vary, so review the result before using it in official documents. It is not a legacy Preeti-font converter.
